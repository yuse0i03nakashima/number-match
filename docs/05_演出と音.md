# 05 演出と音

対象: `web/js/fx.js`、`audio.js`、`css/style.css`。

## 演出の方針

参考にした 3 つの投稿から、それぞれ 1 つずつ取り入れました。

- 猫の宇宙シューティング(550 Atelier): 色に意味を持たせる、触った手応えを返す、何百回も試す。
- その投稿への反応(かぶとむし氏): 画面がきれいでも、音が耳障りだと台無しになる。
- Audio Studio(KANA 氏): 効果音は後から差し替えられるように、生成と再生を分けておく。

色の意味は「熱」に集約しました。チェーン倍率が上がるほど、青から橙、薔薇色、赤へ変わります。選択枠、粒子、HUD の倍率表示、クリア画面の縁がすべて同じ色を使うので、今どれだけ熱いかが一目で分かります。

```js
export function heatColor(heat) {
  const stops = [[0.0, [91,143,249]], [0.4, [245,166,35]], [0.75, [240,98,146]], [1.0, [239,68,68]]];
  ...
}
```

色の計算は 2 つの基準色の間を直線で補間するだけです。CSS 側では `--heat` という変数に入れ、`render.js` が倍率の変化に合わせて書き換えます。

## 粒子の仕組み

Canvas を画面全体に重ね、`requestAnimationFrame` で毎フレーム描き直します。粒子は「位置、速度、寿命、色」を持つ小さなオブジェクトで、配列に入っています。

```js
update(dt) {
  for (const p of this.particles) {
    p.age += dt;
    p.vy += p.gravity * dt;      // 重力
    p.x += p.vx * dt; p.y += p.vy * dt;
  }
  this.particles = this.particles.filter((p) => p.age < p.life);
}
```

`dt` は前のフレームからの経過秒です。これを掛けておくと、画面の更新頻度が違う端末でも同じ速さで動きます。寿命を過ぎた粒子は `filter` で配列から外します。

粒子の数には上限(`maxParticles`)があります。行がいくつも同時に消えると数百個が一度に出るので、古い端末でも止まらないようにするためです。

`globalCompositeOperation = 'lighter'` で描くと、粒子が重なった部分が明るくなり、光っているように見えます。

## 演出の重ね方

1 組消したときの流れは `main.js` の `onRemove` にあります。

1. 2 マスを結ぶ光の線、両端で粒子が爆ぜる、得点の浮き文字。
2. 消えるマスが縮んで消える(CSS アニメ)。
3. 行が消えるなら、ひと呼吸(140 ミリ秒)おいて、横一閃、行全体の粒子、画面の揺れ、白いフラッシュ。
4. ボードを作り直し、スコアを跳ねさせる。

「ひと呼吸おく」のが大事です。2 つの出来事を同時に出すより、少しずらしたほうが両方が見えます。桜井氏の言う「ヒットストップ」に近い考え方で、一瞬止めることで手応えが増します。

揺れは `boardWrap` 要素の `transform` を毎フレーム乱数でずらし、時間とともに小さくします。強さはチェーンの熱で変わります。

## 効果音を合成する

音声ファイルは使わず、WebAudio で波形を直接作ります。ファイルがないので読み込み待ちがなく、調整もコードの数字を変えるだけです。

耳障りにしないために、次の 3 つを守っています。

- 矩形波を使わず、三角波と正弦波にする。倍音が少なく柔らかい。
- 立ち上がりを 5 ミリ秒、減衰を指数的にする。クリック音が出ない。
- 薄いディレイを足す。乾いた電子音にならない。

```js
tone(freq, { type = 'triangle', dur = 0.25, gain = 0.5, attack = 0.005 } = {}) {
  g.gain.setValueAtTime(0.0001, t0);
  g.gain.exponentialRampToValueAtTime(gain, t0 + attack);
  g.gain.exponentialRampToValueAtTime(0.0001, t0 + dur);
}
```

消したときの音はチェーン数に応じてペンタトニック(ド レ ミ ソ ラ)を上っていきます。ペンタトニックはどの順で鳴らしても濁らない音階なので、連鎖がそのまま旋律になります。

```js
const PENTA = [0, 2, 4, 7, 9];
function noteFreq(index) {
  const octave = Math.floor(index / 5);
  const semi = PENTA[index % 5] + 12 * octave;
  return 261.63 * Math.pow(2, semi / 12);
}
```

周波数は基準のド(261.63 Hz)に 2 の「半音数 ÷ 12」乗を掛けて求めます。1 オクターブ上がると 2 倍になる、という音の性質をそのまま式にしたものです。

ブラウザの制約で、音はユーザーが画面に触れた後でないと鳴らせません。`ensure()` が最初のタップで `AudioContext` を作ります。

## 振動

Android の Chrome では `navigator.vibrate` で端末を震わせられます。iPhone では無視されます。消したときは短く、行が消えたときは 3 回、失敗したときは長く、という使い分けです。

## 調整の目安

派手すぎる、物足りない、と感じたら `config.js` の `fx` を変えます。

| 値 | 意味 |
|---|---|
| `particlesPerRemove` | 1 組消したときの粒子の数(片側) |
| `particlesPerRow` | 行が消えたときの粒子の数(1 行あたり) |
| `shakeBase` | 揺れの基本の強さ(ピクセル) |
| `maxParticles` | 画面上の粒子の上限 |

## 演習

1. `heatColor` の基準色を変え、熱の見え方がどう変わるか試す。
2. 消したときの音を、ペンタトニックではなく長音階(ド レ ミ ファ ソ ラ シ)にする。濁って聞こえる組み合わせがあるか確かめる。
3. 行が消えたときの「ひと呼吸」を 0 と 400 ミリ秒にして、手応えの違いを比べる。
